# 🚚 Move It

A modern, responsive landing page for a fictional moving company called **Move It**. This project was built using **HTML5**, **CSS3**, and **Bootstrap 5** to practice responsive layouts, Bootstrap components, and clean UI design.

## 🌟 Overview

Move It is designed to showcase a professional moving service through a visually appealing and mobile-friendly landing page. The website highlights company services, customer benefits, testimonials, and contact options.

## ✨ Features

* Responsive Navigation Bar
* Hero Section with Call-to-Action Buttons
* Services & Features Section
* Bootstrap Carousel
* Mobile-Friendly Layout
* Modern Dark Theme
* Responsive Footer
* Bootstrap Utility Classes

## 🛠️ Technologies Used
